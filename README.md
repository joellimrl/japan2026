# Japan 2026

A static travel blog documenting a 12-day trip through Osaka, Kyoto, and Kobe (April 25 – May 6, 2026).

## Features

- Day-by-day itinerary with activities, food, and photos
- Interactive photo lightbox
- Route map
- Responsive design with side navigation

## Structure

```
index.html          Main travel blog page
map.html            Route map
css/style.css       Styles
js/script.js        Lightbox and navigation logic
photos/             Trip photos and videos
```

## Usage

Open `index.html` in a browser. No build step or server required.
